How it works
1

Add your account

Enter your remoteStorage user address (e.g. user@example.com) in the popup. The extension discovers your storage server via WebFinger.

2

Visit an RS app

When you visit a remoteStorage-compatible app, the extension detects it and offers to connect your account automatically.

3

Approve the connection

You'll see exactly which scopes the app is requesting. Approve once, and the extension authenticates with only those permissions — no global access.

4

Seamless storage

The extension brokers all storage requests securely. Each app gets its own scoped token, and sessions are bound to the tab that created them.

Security

Per-app scoped tokens

Each app receives a token limited to only the scopes it requests — never full access to your storage.

User consent

Every new origin must be approved by you before it can connect. You can revoke access anytime from this page.

Tab-bound sessions

Sessions are tied to the browser tab that created them. A session ID from one tab cannot be used in another.

Origin validation

The extension verifies that the claimed origin matches the actual sender, preventing spoofing attacks.

This extension uses Manifest V3 and runs as a service worker. Tokens are stored in chrome.storage.local and never exposed to web pages. Learn more about remoteStorage.
